## 1. Project Identity

Self Localized Systems Theory (SLST) is a standalone educational and analytical system derived from the broader Local Systems Theory work, but maintained as a separate project.

SLST models the self as a dynamic local system made of interacting cognitive, emotional, behavioral, social, and environmental nodes.

## 3. Primary User Roles

### Learner
Completes the questionnaire, receives track placement, attends course modules, and completes quizzes/exams.

### Instructor
Views assigned learners, class blocks, learner progress, questionnaire insights, and instructional flags.

### Admin
Manages users, instructors, class capacity, dashboard access, questionnaire settings, analytics, and reporting.

## 5. Current Questionnaire Structure

The SLST Self-Integrity Questionnaire has 20 questions across 4 subscales:

1. Identity Clarity
2. Identity Stability Under Stress
3. External Dependency
4. Internal Coherence

Section C, External Dependency, is reverse scored.
