# Self Localized Systems Theory — MVP Scaffold

This is a scaffolded MVP for the SLST platform.

## Includes

- Landing page
- 20-question Self-Integrity Questionnaire
- Reverse scoring for questions 11–15
- Track assignment:
  - Observed / Core
  - Observer / Intermediate
  - Observing / Advanced
- Internal dashboard mock
- Learner analytics mock
- Class block capacity logic
- Course module outline
- Planning docs

## Run Locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Important

This scaffold uses mock/local client-side state. It is not production-ready.

Before production:
- Add database persistence
- Add authentication
- Add role-based access controls
- Add consent language
- Add privacy policy
- Add secure export controls
